# The Robot Vacuum's Best Excuse

A one-line excuse a robot vacuum gives for missing a spot, 140 characters or fewer. `main.py` (Python 3.13, standard library only, no network) writes it to `/output/entry.txt`.

> My cliff sensor saw the dark rug, yelled 'lava,' and filed that spot under 'do not cross.' I don't argue with lava.

## Why this line

- **First-person vacuum voice** — the machine itself talking, deadpan, keeping a straight face.
- **Rooted in the vacuum's own world** — its cliff sensor, the classic robot-vacuum failure mode of mistaking a dark rug for a drop.
- **Clean turn at the end** — "I don't argue with lava" lands on the first read with no setup to explain.

## Running it

```sh
python3 main.py   # writes /output/entry.txt (115 chars, single line)
```
